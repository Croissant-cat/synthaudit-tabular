# SynthAudit

**Auditing generative augmentation for imbalanced tabular learning: a controlled comparison of VAE, GAN and DDPM.**

This repository contains the code, experiment configuration and results for a data-analysis
project on synthetic tabular data. It implements three generative model families from
scratch on a shared mixed-type representation and evaluates them along four axes:
distributional fidelity, diversity, privacy, and downstream predictive utility.
